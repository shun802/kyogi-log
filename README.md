# 競技ログ

アルティメットの練習・試合を記録する、個人用のiPhone向けWebアプリです。

- `index.html` … アプリ本体（1ファイル、ライブラリなし）。記録はブラウザの localStorage に保存されます。
- Claudeアプリ内で開いた場合は、同じファイルがアカウント保存（db）を使います。
- `sw.js` … オフライン用。オンライン時は常に最新を取得し、オフライン時だけ保存済みを使います。
- `quiz/` … 別アプリ（ルールクイズ）。このアプリとは独立しています。
- 記録の保存先はそのiPhoneのそのアプリ内です。画面下の「バックアップ・復元」で定期的に控えを取ってください。
- iPhoneでは、Safariで入れた記録と、ホーム画面に追加したアプリの記録は別々に保存されます。
